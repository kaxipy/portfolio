ჩემი ტექნოლოგიური უნარები

ტექნოლოგიები და ინსტრუმენტები, რომლებსაც აქტიურად ვიყენებ და ვსწავლობ

  • HTML5 & Semantic Web

    სემანტიკური თეგები, ფორმები, ვალიდაცია და ხელმისაწვდომობა (a11y).

  • CSS3 & Responsive Web

    Flexbox, CSS Grid, Media Queries (შესწავლის პროცესში).

  • JavaScript (ES6+)

    DOM მანიპულაციები, ასინქრონული ფუნქციები, API ინტეგრაციები.

  • Git & GitHub

    ვერსიების კონტროლი და გუნდური მუშაობის პრინციპები.

  • AI ხელსაწყოები

    Antigravity IDE, Google Gemini - კოდის დაგეგმვისა და ოპტიმიზაციისთვის.
